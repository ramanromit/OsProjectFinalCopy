Layer 2: I/O Heuristic Logic

  • Triggered only if Layer 1 yields no rule matches.
  • Background if: write_bytes / total > 70% (bulk sequential writer).
  • Critical if: read_syscalls > 200/s (interactive/latency sensitive).
  • Fallback to background if ambiguous to preserve system safety.
